# Engineering Conventions

## Conventions

> When writing code, follow these conventions.

- Write simple, verbose code over terse, compact, dense code.
- For icons, stick with svelte components.
- When creating component variants, only use pre-existing components.

## Project Structure

- `src/lib/components` - Svelte components for app
- `src/lib/icons/` - Svgs as svelte components
- `src/lib/utils/` - Typescript utilities
